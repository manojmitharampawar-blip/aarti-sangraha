## 🛠️ Step-by-Step Guide for Video Generation AI Models

### How to use these prompts in:
1. **Runway Gen-3 Alpha:**
   - Choose `Text to Video` or `Image to Video`.
   - Use the provided 1200x630 `public/og-image.jpg` or a vertical still as the First Frame input.
   - Paste the AI Video Generation Prompt into the prompt box.
   - Set Duration to `10s` and Motion to `5-6`.
2. **OpenAI Sora / Kling AI / Luma Dream Machine:**
   - Set aspect ratio to `9:16` (Vertical).
   - Enter camera directions: `Smooth camera dolly push-in, cinematic warm temple lighting, shallow depth of field, photorealistic 8k`.
   - Run prompt and download the rendered 10-second MP4.
3. **Audio & Voiceover Pairing:**
   - Use **ElevenLabs** or **Murf.ai** with a warm, authentic Marathi voice (e.g., *Aarav* or *Kavita*) speaking with devotional reverence.
   - Overlay the provided Sound FX (Temple bell, shankh, tanpura drone) using CapCut, Premiere Pro, or InShot.
   - Add auto-captions in bold Marathi font (*Mukta* or *Baloo 2*) with saffron/gold text fill.
